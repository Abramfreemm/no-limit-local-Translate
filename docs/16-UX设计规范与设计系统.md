## 0. 为什么桌面工具也需要设计系统

当前 UI 由 11 个文件一次性写成，四页 + 一个预览弹窗，每页各自设颜色、边距、字号。这带来三个具体问题：

1. **不一致**：任务页的次要文字是 `#666`，设置页用 `#888`，术语表页用 `QPalette` 默认灰。同一层信息，三种观感。
2. **改不动**：想统一调一次圆角，要改 11 个文件。
3. **测不了**：没有 token 就没有"设计验收"这个环节，UI 正确性只能靠肉眼。

设计系统的目标不是"好看"，是**让一致性可执行、可验证**。

## 1. 设计原则（四条，冲突时按顺序取舍）

| # | 原则 | 含义 | 反面案例 |
|---|---|---|---|
| P1 | **状态优先于装饰** | 任何时刻用户要能一眼看出"现在进行到哪、有没有出问题"。留白与边框服务于状态表达，不用于好看 | 给表格加斑马纹却不标失败行 |
| P2 | **默认值就是正确答案** | 90% 用户不改设置。所有默认值必须是"最安全的选择" | 默认输出成 Markdown（用户预期是 PDF） |
| P3 | **不打断** | 只有必须由用户决策的事才弹模态。可后台进行的一律后台 | 模型下载弹模态，锁死整个应用 |
| P4 | **可撤回** | 破坏性操作（清空队列、删除术语）必须有确认或可撤销 | 点一下就删掉 800 页任务进度 |

## 2. Design Tokens

所有数值都在 `linguaforge/ui/theme/tokens.py` 中定义为常量，QSS 由此生成。**代码里禁止出现裸的十六进制颜色与像素值。**

### 2.1 颜色

**中性色阶**（浅色主题，用于背景、边框、文字）

| Token | 值 | 用途 |
|---|---|---|
| `bg.canvas` | `#FFFFFF` | 内容区底色 |
| `bg.subtle` | `#F7F8FA` | 页面底色、表头 |
| `bg.muted` | `#EEF0F3` | 禁用控件底、进度槽 |
| `border.default` | `#DFE2E7` | 分割线、输入框边框 |
| `border.strong` | `#C4C9D1` | 悬停边框、表头下边线 |
| `text.primary` | `#1B1F24` | 标题、正文 |
| `text.secondary` | `#5A626E` | 说明、次要信息 |
| `text.tertiary` | `#8A919C` | 占位符、禁用文字 |

**语义色**（每色四档：fg / bg / border / hover）

| Token | fg | bg | 用途 |
|---|---|---|---|
| `accent`（品牌蓝） | `#1F6FEB` | `#EAF2FE` | 主按钮、选中态、链接 |
| `success` | `#17803D` | `#E9F7EE` | 完成状态、校验通过 |
| `warning` | `#9A6700` | `#FFF8E1` | 部分完成、OCR 低置信、环境提醒 |
| `danger` | `#C4291C` | `#FDECEA` | 失败、不可恢复错误 |
| `info` | `#0969DA` | `#EAF2FE` | 中性提示 |

**规则**：
- 状态色**只用于状态**，不得用于装饰（例如"开始"按钮用 accent，不用 success）。
- 文字压在同色 bg 上时，对比度必须 ≥ 4.5:1（见 §7）。

### 2.2 字号与行高

| Token | px | 行高 | 用途 |
|---|---|---|---|
| `font.caption` | 11 | 16 | 时间戳、字节数、辅助元信息 |
| `font.body-sm` | 12 | 18 | 表格内容、说明文字 |
| `font.body` | 13 | 20 | **默认正文**（设置项、描述） |
| `font.title-sm` | 15 | 22 | 卡片标题、页内小标题 |
| `font.title` | 18 | 26 | 页面标题 |
| `font.display` | 24 | 32 | 空态主文案（"把文件拖到这里"） |

字体族：`"Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", system-ui, sans-serif`
数字与代码：`"JetBrains Mono", "Cascadia Mono", Consolas, monospace`（用于页数、耗时、哈希，保证等宽对齐）

### 2.3 间距（4 px 基数）

| Token | px | 典型用途 |
|---|---|---|
| `space.1` | 4 | 图标与文字间距 |
| `space.2` | 8 | 控件内边距（紧凑）、行内元素间隔 |
| `space.3` | 12 | 表单行间距 |
| `space.4` | 16 | 卡片内边距、区块间距 |
| `space.6` | 24 | 页面边距 |
| `space.8` | 32 | 大区块分隔、空态留白 |

### 2.4 圆角、边框、阴影

| Token | 值 | 用途 |
|---|---|---|
| `radius.sm` | 4 px | 输入框、标签、徽标 |
| `radius.md` | 6 px | 按钮、卡片 |
| `radius.lg` | 10 px | 模态、拖放区 |
| `border.width` | 1 px | 默认；聚焦时 2 px accent |
| `shadow.card` | `0 1px 3px rgba(16,24,40,.08)` | 卡片 |
| `shadow.modal` | `0 8px 28px rgba(16,24,40,.16)` | 模态、Toast |

### 2.5 动效

| Token | 值 | 用途 |
|---|---|---|
| `motion.fast` | 120 ms ease-out | hover、按下 |
| `motion.base` | 200 ms ease-out | 展开/折叠、Toast 进出 |
| `motion.slow` | 320 ms ease-in-out | 页面切换 |

**规则**：进度条与耗时数字**不做动画**（用户要看真实数值，插值会造成"假进度"）。系统设置"减少动态效果"时，所有过渡降为 0 ms。

## 3. 布局

### 3.1 窗口

| 项 | 值 |
|---|---|
| 最小尺寸 | 900 × 620 |
| 默认尺寸 | 1120 × 720 |
| 侧边导航宽度 | 168 px（可折叠至 56 px） |
| 内容区最小可用宽度 | 720 px |
| 页面内边距 | 24 px（`space.6`） |
| 状态栏高度 | 28 px |

### 3.2 栅格

内容区按 12 列、列间距 16 px 布局。常用模式：

- **单列表单**：标签 180 px 固定 + 控件自适应（不居中，左对齐）
- **双列卡片**：6/6 均分
- **表格页**：全宽，工具条固定在表格上方 12 px

### 3.3 层级（z 序）

```
页面内容 < 固定工具条 < 侧边导航 < 顶部健康条 < Toast < 模态 < 系统对话框
```

Toast 在模态**之下**（模态打开时不显示 Toast，避免误以为模态内的反馈）。

## 4. 组件规格

### 4.1 按钮

| 类型 | 底色 | 文字 | 用途 | 每屏上限 |
|---|---|---|---|---|
| Primary | `accent` | 白 | 每屏唯一主操作（开始翻译） | **1 个** |
| Secondary | 白 + `border.default` | `text.primary` | 次要操作（选择目录） | 不限 |
| Ghost | 透明 | `accent` | 行内操作（重试 / 打开） | 不限 |
| Danger | 白 + `danger` 边框 | `danger` | 删除类 | 谨慎 |

尺寸：高 30 px（默认）、26 px（表格行内）、34 px（空态主按钮）。水平内边距 `space.3`。

**状态**：`normal / hover / pressed / focus / disabled / loading`
- `disabled`：底色 `bg.muted`，文字 `text.tertiary`，**必须有 tooltip 说明为什么禁用**（这是最常被忽略的一条）。
- `loading`：文字左侧 14 px 旋转指示，文字改为进行时（"正在开始…"），**按钮不禁用**（允许取消）。

### 4.2 输入框

- 高 30 px，内边距 8 px，`radius.sm`，`border.default`。
- `focus`：边框 2 px `accent`，**不加外发光**（避免与卡片阴影混淆）。
- 错误态：边框 `danger`，下方 4 px 处 11 px 红字说明。
- 占位符用 `text.tertiary`，不得用占位符代替标签（标签必须常驻）。

### 4.3 表格（任务队列）

| 项 | 规范 |
|---|---|
| 行高 | 36 px（`font.body-sm` 单行） |
| 表头 | `bg.subtle`、下边框 `border.strong`、字重 600、**不滚动** |
| 斑马纹 | 不用（见 P1：颜色留给状态） |
| 悬停 | 行底 `bg.subtle` |
| 选中 | 行底 `accent.bg`，左侧 3 px `accent` 竖条 |
| 状态列 | 徽标（见 4.5），**文字 + 颜色双编码**（不可只靠颜色，见 §7） |
| 长文件名 | 中间省略（`论文合集…第3章.pdf`），tooltip 显示全名 |

### 4.4 进度条

- 高 6 px，槽 `bg.muted`，条 `accent`，`radius.sm`。
- **必须同时显示数值**（"324 / 800 页 · 40%"），不能只有条。
- 不可确定进度（如"正在解析"）用流动条纹，不用假百分比。
- 部分失败：进度条在对应位置留 2 px 宽的 `warning` 缺口，让用户看到"坏在哪一段"。

### 4.5 状态徽标

| 状态 | 文字 | 前景/背景 | 图标 |
|---|---|---|---|
| 待处理 | 待处理 | tertiary / muted | 无 |
| 解析中 | 解析中 | info / info-bg | 无（有进度条） |
| 翻译中 | 翻译中 42% | info / info-bg | 无 |
| 完成 | 完成 | success / success-bg | ✓ |
| 部分完成 | 完成（3 页失败） | warning / warning-bg | ! |
| 失败 | 失败 | danger / danger-bg | ✕ |
| 已取消 | 已取消 | tertiary / muted | — |

规格：高 20 px，左右内边距 6 px，`radius.sm`，`font.caption`。

### 4.6 空态

每个页面必须有空态，三要素：**一句说明 + 一个主操作 + （可选）一个示例/模板**。

| 页面 | 主文案 | 副文案 | 主操作 |
|---|---|---|---|
| 任务 | 把文件拖到这里 | 支持 PDF、Word、PPT、Excel、字幕、图片 | 选择文件 |
| 模型 | 还没有可用模型 | 先下载一个模型才能开始翻译 | 下载推荐模型 |
| 术语表 | 还没有术语表 | 导入 CSV 或用模板开始 | 下载模板 |
| 预览 | （不适用，无内容时不打开） | — | — |

### 4.7 Toast

- 位置：右下，距边 24 px，距底 40 px（避开状态栏）。
- 宽 280–360 px，`radius.md`，`shadow.modal`。
- 结构：图标 + 一行文字 + （可选）一个动作。
- 最多同时 3 条，超出则替换最旧的一条。
- 成功类 4 s 自动消失；带动作的 8 s；错误不用 Toast（走内联或模态）。

### 4.8 模态

- 宽 420 px（确认）/ 560 px（表单）/ 最大 880 px（预览）。
- 结构：标题（18px）+ 正文（13px，≤120 字）+ 按钮组（右下，Secondary 在左、Primary 在右）。
- **必须有 Esc 关闭**；破坏性模态的默认焦点在"取消"而非"确认"。
- 背景遮罩 `rgba(16,24,40,.32)`，点击遮罩**不关闭**（防止误触丢失上下文）。

## 5. 交互状态清单（每个可交互元素都要有）

| 状态 | 视觉 | 可访问性要求 |
|---|---|---|
| normal | 默认 | — |
| hover | 底色加深 4–6% 或边框 `border.strong` | 仅鼠标态，键盘不依赖 |
| focus | 2 px `accent` 外框（`outline-offset: 1px`） | **键盘必须可见** |
| pressed | 底色再加深 8%，无位移 | — |
| disabled | `bg.muted` + `text.tertiary` | 必须可被读屏识别为 disabled；必须有 tooltip 说明原因 |
| loading | 指示器 + 进行时文案 | 读屏播报"正在…" |
| error | `danger` 边框 + 下方说明 | 读屏播报错误文本 |

## 6. 中文排版规则（CJK 专项）

这些规则在 Qt 里不会自动生效，必须手工处理。

| 规则 | 做法 |
|---|---|
| 中英混排加空格 | 中文字符与英文/数字之间插入半角空格：「支持 PDF 与 DOCX」「共 1,847 页」 |
| 标点全角 | 中文语境用全角标点（，。；：！？），英文与代码保持半角 |
| 不拆词换行 | 文件名、模型名（`translategemma:12b`）不得在中间断行，用 `word-wrap: normal` + 省略号 |
| 数字等宽 | 页数、耗时、百分比使用等宽字体，避免跳动（进度从 9% → 10% 时列宽不变） |
| 避免孤字 | 标题换行时不允许最后一行只有 1 个汉字（用 `text-wrap: balance` 或手动画断点） |
| 省略号 | 用「…」而非「...」 |

## 7. 无障碍（Accessibility）

| 项 | 要求 | 验证方法 |
|---|---|---|
| 对比度 | 正文 ≥ 4.5:1；大字（≥18px）≥ 3:1 | 用对比度计算器逐对校验 §2.1 的所有 fg/bg 组合 |
| 键盘可达 | 所有功能可仅用键盘完成 | 拔掉鼠标走完 §2 旅程 A |
| 焦点顺序 | 与视觉顺序一致（左→右、上→下） | Tab 逐个数，不跳、不绕 |
| 焦点可见 | 2 px accent 外框，任何背景下都可见 | 在 `bg.subtle` 与 `bg.canvas` 上各验一次 |
| 不靠颜色 | 状态徽标必须有文字；错误行必须有图标 | 灰度截图后仍可区分全部状态 |
| 读屏 | 所有控件有 `accessibleName`；进度用 `value now/min/max` | Windows 讲述人走一遍任务页 |
| 缩放 | 125% / 150% / 200% DPI 下无裁切、无重叠 | 系统缩放逐档验证 |
| 减少动效 | 尊重系统设置，过渡降为 0 | 开启后观察 |

## 8. Qt / PySide6 落地方式

### 8.1 Token → 代码

```python
# linguaforge/ui/theme/tokens.py
BG_CANVAS = "#FFFFFF"
BG_SUBTLE = "#F7F8FA"
TEXT_PRIMARY = "#1B1F24"
ACCENT = "#1F6FEB"
SPACE_4 = 16
RADIUS_MD = 6
FONT_BODY = 13


def build_qss() -> str:
    """由 token 生成全局 QSS；唯一允许出现裸数值的地方。"""
    return f"""
    QWidget {{ background: {BG_CANVAS}; color: {TEXT_PRIMARY};
               font-size: {FONT_BODY}px; }}
    QPushButton#primary {{ background: {ACCENT}; border-radius: {RADIUS_MD}px;
                           padding: 6px 12px; color: white; }}
    QTableView {{ alternate-background-color: {BG_CANVAS};
                  gridline-color: transparent; }}
    """
```

**约束**：
- `app.py` 启动时 `app.setStyleSheet(build_qss())` 一次。
- **禁止在页面文件里写 `setStyleSheet("color:#666")`**——这是当前 11 个文件的主要问题，也是 V1.1 要清理的对象。
- 需要动态色（如失败行）通过 `QStyledItemDelegate` 取值自 tokens，不写死。

### 8.2 高 DPI

```python
QApplication.setHighDpiScaleFactorRoundingPolicy(Qt.HighDpiScaleFactorRoundingPolicy.PassThrough)
```
- 所有尺寸用 px（Qt 会按 DPI 缩放），不用 pt。
- 图标用 SVG 或 2 倍图，禁止用小尺寸 PNG 放大。

### 8.3 图标

- 统一 16 / 20 / 24 三档，线宽 1.5 px，圆角端点。
- 颜色随 `text.primary` / `text.secondary`，不用彩色图标（例外：状态徽标内的 ✓ / ! / ✕）。
- 当前 `resources/icons/` 只有应用图标，**功能图标尚未系统化** —— 这是 V1.1 待办。
