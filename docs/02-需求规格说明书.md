# 02 · 需求规格说明书（SRS）

版本 v2.0 ｜ 状态：已确认 ｜ 日期：2026-10-29 ｜ 决策：D4 / D8 / D10 / D16

## 1. 产品概述

LinguaForge 是一个**完全本地运行**的桌面文档翻译器。它读取本地文件，必要时做离线 OCR，把内容交给用户本机 Ollama 中的开源模型进行翻译，最后按原格式或指定格式输出译文。**任何字节都不会离开本机。**

## 2. 用户画像与核心场景

| 场景 | 典型动作 | 关键诉求 |
|---|---|---|
| 科研人员 | 拖入一篇 60 页英文论文，译成中文双语 PDF | 公式、图表、参考文献不能乱 |
| 法务 / 商务 | 一份 300 页扫描合同，英译中 | 隐私第一、页数不限、可断点 |
| 工程人员 | 一本 900 页英文设备手册（PDF + 图片） | 扫描件 OCR、大文件不崩、可检索 |
| 学习者 | SRT / VTT 字幕批量翻译 | 保持时间轴与序号 |
| 办公 | DOCX、PPTX、XLSX 成批翻译 | 保持样式、表格、母版 |

## 4. 非功能需求

| 类别 | 指标 |
|---|---|
| 性能 | OCR ≤ 2 s/页（CPU，200 DPI，RapidOCR）；翻译吞吐取决于模型与硬件，UI 需给出实时估算 |
| 内存 | 1000 页任务峰值 RSS ≤ 1.5 GB（不含 Ollama 自身进程） |
| 稳定性 | 单页 OCR/翻译失败不得中断整体任务；崩溃后重启可续跑 |
| 启动 | 冷启动至主窗口可见 ≤ 5 s；OCR 与翻译后端延迟加载 |
| 离线 | 断网全流程可用；**零外发请求**（D8 已取消检查更新），由 P3-4 的 `trust_env=False` + 无 socket 测试保障 |
| 体积 | Windows 安装包 ≤ 400 MB；macOS dmg ≤ 400 MB |
| 兼容 | Windows 10 1809+ / macOS 12+（arm64 与 x86_64） |
| 安全 | 不写入用户文档目录以外的位置；临时文件集中在应用数据目录，退出可清理 |
| 可维护 | 核心流水线与 UI 解耦，可无头（headless）运行并单测 |

## 5. 验收口径（对应 G1/G2）

| 验收项 | 方法 | 通过标准 |
|---|---|---|
| A1 离线 | 断网 + 防火墙阻断，跑一遍完整流程 | 无外发连接；流程成功 |
| A2a 大文件·页数 | 1000 页 PDF（不限体积，含扫描页） | 完整跑完，峰值 RSS ≤ 1.5 GB，无 OOM |
| A2b 大文件·体积 | ≥ 500 MB PDF | 完整跑完，峰值 RSS ≤ 1.5 GB，无 OOM（**从未测过，属 0.2.0 P8-1**） |
| A3 断点 | 跑到 40% 强制杀进程，重启 | 从 40% 续跑，已完成部分不重翻 |
| A4 排版 | 论文/手册/多栏报告 各 1 份 | 3 位评审均分 ≥ 3.5/5 |
| A5 安装 | 干净 Win11 / 干净 macOS 各 1 台 | 安装成功 + 样例翻译成功 |
| A6 OCR | 300 dpi 扫描中文/英文各 10 页 | 字符准确率 ≥ 95%（英文）/ ≥ 92%（中文） |

## 6. 用户交互主流程

```
启动 → 自检（Ollama / 模型 / OCR 就绪）
     → 拖入文件 → 自动识别格式与是否需要 OCR
     → 选择：源语言 / 目标语言 / 模型 / 输出模式
     → （可选）加载术语表
     → 开始 → 实时进度（页/段/吞吐/ETA）→ 可暂停
     → 完成 → 打开输出目录 / 预览对照
```
