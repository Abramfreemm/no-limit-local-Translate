## 2. 5 分钟速览

### 产品形态
- **桌面 GUI（Windows / macOS）+ CLI**，PySide6 + PyInstaller 打包
- **100% 本地**：解析、OCR、翻译、排版重建全部在本机进程内完成
- **翻译引擎**：复用本机 **Ollama**（`127.0.0.1:11434`），不内置任何模型权重
- **OCR**：内置 RapidOCR ONNX（约 15 MB），随包分发

### 支持范围

> 以下格式数量以代码 `pipeline.SUPPORTED_IN` 与 `OUT_EXT` 为唯一真相源（当前：20 个输入扩展名 ≈ 14 种格式；8 种输出格式，由 7 个写出模块承担 —— `srt_writer` 兼写 SRT 与 VTT）。

| 类别 | 格式 |
|---|---|
| 文档 | PDF（文本/扫描/混合）、DOCX、PPTX、XLSX、HTML、TXT、Markdown |
| 字幕 | SRT、VTT |
| 图片 | PNG、JPG、TIFF、BMP、WebP（走 OCR） |
| 输出 | 7 种格式：Markdown / TXT / PDF（原位回填）/ DOCX / PPTX / XLSX / SRT；另支持双语对照（开关，非格式）与 VTT 写入（内核支持，UI 暂未暴露） |

**明确不支持（V1.0）**：EPUB、ODT、RTF、CSV、加密文档、手写体高精度识别（见 15 号 §4）。

### 「不限制页数与大小」的六条落点
1. 全流式按页处理，内存只保留当前页窗口
2. 磁盘即真相：中间结果写入 SQLite（WAL）
3. 断点续翻：每页/每块有状态，中断后从断点继续
4. 无硬编码上限：不存在 `MAX_PAGES` / `MAX_FILE_SIZE`
5. 超大文件分片（>300 MB 或 >800 页）
6. 内存护栏 + 降档（**待实现**，0.2.0 P5-1，见 21 号 §4-5）

**实测佐证**：1000 页解析耗时 27 s、RSS 增量仅 9.6 MB（18 号 §4.1）。

## 5. 文档纪律

1. **编号不复用**，新增文档递增编号。
2. **单一真相源**：任何"数量 / 支持范围 / 状态"只能有一处定义，其他地方引用。当前唯一真相源是**代码 + 21 号**。
3. **每份文档末尾必须有状态行**：待评审 / 已确认 / 已废弃。
4. **代码改动影响文档时，同一 PR 内更新**。
5. 文档不是越全越好 —— `15` 号已明确砍掉 5 项功能，`21` 号 §11 明确 6 项不做。**删除决策也要记录理由。**
