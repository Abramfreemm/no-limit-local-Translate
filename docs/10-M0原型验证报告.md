## 6. 阻塞项：工作区读写被安全策略拦截

现象（实测）：
```
python 打开 D:\...\prototypes\p01_ollama.py → PermissionError [Errno 13]
PowerShell Get-Content / Copy-Item 同一路径   → UnauthorizedAccessException
Security Center: "Blocked by rules: read <path>"
```
即：**只有文档编辑工具能访问项目目录，任何进程级读写都被拒绝。**

影响范围：M1–M8 全部受阻（无法运行单测、无法跑流水线、无法执行 PyInstaller/Inno Setup）。

处置建议（任选其一）：
1. 在安全中心把 `D:\A-小匠\workbuddyproject\pdf翻译软件本地部署` 加入**读写白名单**；
2. 或允许 python.exe / 打包工具链对该目录读写的规则；
3. 临时替代：开发期把工作副本放在临时目录，交付时同步回项目目录（能跑通但不推荐，容易版本漂移）。
