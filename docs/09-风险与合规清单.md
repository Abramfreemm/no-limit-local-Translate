## 2. 技术风险

| # | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R1 | PDF 原位回填排版质量不达标 | 高 | 高 | M2 单独成里程碑；保留 Markdown 降级输出；建立评分表持续迭代；提供"译文覆盖模式/重排模式"两种 |
| R2 | 大文件内存失控 | 中 | 高 | 逐页流式 + SQLite + 内存护栏 + 分片；F12 压力样本必测 |
| R3 | Ollama 输出不稳定（漏翻、加戏、条数不对） | 高 | 中 | 编号化 + JSON + 校验 + 三级降级链 + 低温度 |
| R4 | 打包漏文件导致运行崩溃 | 中 | 高 | 每次构建后在干净虚拟机实跑；CI 加冒烟测试 |
| R5 | macOS 未签名拦截 | 高 | 中 | ad-hoc 签名 + 明确指引；正式分发购 Developer ID |
| R6 | 杀毒软件误报 | 中 | 中 | onedir 模式；签名；准备申诉材料 |
| R7 | OCR 对公式/手写无能为力 | 高 | 低 | 明确声明能力边界；公式块识别为"不翻译"并原样保留 |
| R8 | 中文字体体积与嵌入失败 | 中 | 中 | 子集化；reportlab TTF 注册校验；提供字体缺失时的降级字体与提示 |
| R9 | Apple Silicon 上依赖无 arm64 wheel | 中 | 高 | 选型阶段已确认（onnxruntime / pypdfium2 均有 arm64）；CI 中加架构断言 |

## 3. 隐私与数据

| 项 | 承诺 |
|---|---|
| 外发请求 | 除"检查更新"（GitHub Release API）外**零外发**；该开关默认开但可在设置中关闭 |
| 文档内容 | 仅在本机进程与本机 SQLite 中流转；Ollama 走 `127.0.0.1` |
| 遥测 | **不做任何遥测、埋点、崩溃上报** |
| 数据目录 | Windows：`%LOCALAPPDATA%\LinguaForge`；macOS：`~/Library/Application Support/LinguaForge` |
| 卸载 | 卸载程序询问是否保留用户数据（术语表、翻译记忆） |
| 临时文件 | 集中在数据目录 `cache/`，退出或任务清理时删除 |

## 4. 法律与分发

- 应用名与图标需避免与现有商标冲突（立项时建议检索一次）
- 若使用 Noto 字体，须在安装包内附 OFL-1.1 全文
- 若分发到国内渠道，注意《生成式人工智能服务管理暂行办法》对"面向公众提供服务"的备案要求 —— **本项目是纯本地工具，不对外提供生成服务，不构成备案义务**；但仍建议在 README 中声明"本工具不提供任何在线服务"
